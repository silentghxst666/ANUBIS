# ANUBIS — лекала утеплённой перчатки

Параметрические лекала перчатки «driver» (кожаная ладонь + технический тыл + утеплитель).
Версия 0.1 — базовый мужской размер M (9), до пробного образца.

## Файлы (`out/`)
| Файл | Что это |
|---|---|
| `glove-M-shell-A4.pdf` | верх: печать на A4, склейка по крестикам (1-я страница — схема) |
| `glove-M-lining-A4.pdf` | подкладка / утеплитель, то же для A4 |
| `glove-M-*-fullsize.pdf` | один большой лист 1:1 — для печати в типографии / на плоттере |
| `glove-M-*.dxf` | для CLO3D (File → Import → DXF), слои CUT / SEAM / NOTCH / MARK, мм |
| `glove-M-techpack.pdf` | техзадание для мастера: мерки, крой, материалы, порядок пошива |

Печатать **в масштабе 100 %** и проверить контрольный квадрат 100 × 100 мм.

## Пересобрать после правок
Все размеры — в `SIZE` в начале `geometry.js` (мм). Изменить и выполнить:

```bash
npm install
npm run build
```
