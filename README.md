# ANUBIS
ANUBIS - a designer clothing e-commerce platform built around a dark, minimal, and exclusive aesthetic. The store features limited clothing collections, bold visual identity, and a curated shopping experience designed for those who reject the ordinary.

Live: https://sibuna.net

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000 — you'll be redirected to `/en` or `/ru` based on browser language.

Stack: Next.js (App Router), TypeScript, Tailwind CSS. Deployed on Vercel; every push to `main` goes live.
